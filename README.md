## 🌟 ميزات المنصة المحلية

تم تصميم هذا المستودع ليكون **منصة بحثية متكاملة وخفيفة (All-in-One)** تعمل محلياً على جهاز أي باحث أو طالب علم دون أي تعقيدات:

* **بدء فوري بدون قيود تسجيل (Zero-Friction Access)**: تم إلغاء شاشات الدخول والحسابات الخارجية، والمنصة تمنح كل مستخدم صلاحيات "باحث محلي" فور تشغيلها.
* **إلغاء قيود الاشتراك (All Features Unlocked)**: استوديو الوكيل الذكي، وتصدير الملفات التوثيقية، وحساب التناظر اللفظي (Palindrome)، ومحركات الإحصاء متاحة بالكامل مجاناً دون أي Paywall.
* **واجهة مريحة ومطابقة للمصحف**: تصميم أبيض هادئ ومريح للعين مع صفحة مصحف حقيقية متدفقة بالرسم العثماني وعلامات الأحزاب والأجزاء وفواصل الآيات المزخرفة ﴿١﴾.
* **اكتفاء ذاتي كامل**: لا تحتاج إلى تشغيل خادم خلفي منفصل؛ التطبيق يخدم الواجهات ومسارات الـ API بالكامل داخل Next.js 16 عبر معالجات مسارات مدمجة.

## 🚀 التشغيل السريع بأمر واحد

### المتطلبات الأساسية:
* **Node.js** الإصدار `20.x` أو أعلى.
* مدير الحزم **npm** أو **pnpm**.

### خطوات التثبيت والتشغيل:
```bash
# 1. استنساخ المستودع
git clone git@github.com:racsou/quranmind.git
cd quranmind

# 2. تثبيت الحزم (مرة واحدة فقط)
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح مباشرة على:
👉 **`http://localhost:3002/dashboard`**

## 🧭 المعمارية ومختبر البحث ثلاثي الألواح

توفر شاشة **الرئيسية (`/dashboard`)** مساحة عمل بحثية متكاملة مقسمة إلى ثلاثة ألواح تفاعلية متزامنة في النسق العربي (RTL):

```
┌─────────────────────────┬──────────────────────────────┬─────────────────────────┐
│     لوحة الأدلة         │      المصحف المتدفق          │    استوديو الوكيل       │
│  والتحليل المقارن       │   وشبكة التحليل الرياضي      │    البحثي الذكي         │
│  (Exact Evidence)       │       (Exact Quran)          │    (Exact Agent)        │
├─────────────────────────┼──────────────────────────────┼─────────────────────────┤
│ • التناظر اللفظي        │ • صفحة المصحف برسم المدينة   │ • حوار بحثي ذكي         │
│ • حساب الجمل الكبير     │ • البسملة ولوحة السورة       │ • اقتراحات استعلام جاهزة│
│ • المواضع الدلالية      │ • شريط عائم لتحديد الآية     │ • استدعاء سياق الآيات   │
│ • مراجع التفاسير المعتمدة│ • توزيع الحروف ونسب التكرار  │ • استدلال رياضي ومنهجي  │
└─────────────────────────┴──────────────────────────────┴─────────────────────────┘
```

* **التبديل بين الأنماط**: يتضمن شريط التبويب العلوي زراً للتبديل الفوري بين **التحليل الثلاثي (Three Panes)** و **ملخص الأنشطة (Activity Cards)**.

## 🧠 إعداد محركات الذكاء الاصطناعي

من خلال صفحة الإعدادات المبسطة (`/dashboard/settings`)، يمكنك ضبط محركات الاستدلال:

1. **النماذج المدعومة**:
   * `Google Gemini 2.5 Flash` (فائق السرعة والموصى به للدراسات القرآنية).
   * `Google Gemini 2.5 Pro` (للبحث المعمق والاستدلال المعقد).
   * دعم اختياري لـ `GPT-4o` و `Claude 3.5 Sonnet` و `DeepSeek R1`.
2. **المفتاح المخصص (Custom API Key)**:
   * المنصة تعمل محلياً بالمفتاح المدمج، ويمكنك إضافة مفتاحك الخاص من **Google AI Studio** لحصص استعلام أعلى.
3. **درجة الحرارة والدقة (Temperature)**:
   * من `0.0` (دقة رياضية حازمة) إلى `0.2` (موصى به للقرآن) إلى `1.0` (إبداعي واسع).
4. **الأنماط البحثية المنهجية**:
   * التناظر البنيوي والإعجاز العلمي واللغوي.
   * الاشتقاق المعجمي وتتبع الجذور القرآنية.
   * الاستدلال الموضوعي والمقارن.

## 📡 دليل الواجهة البرمجية المفتوحة (Public REST API)

يتضمن التطبيق واجهة برمجية مفتوحة متوافقة مع معيار `ilm` ومواصفة `OpenAPI 3.1` تعمل على `http://localhost:3002/v1`:

| المسار | الطريقة | الوصف | مثال استعلام Curl |
| :--- | :---: | :--- | :--- |
| `/v1/quran/surahs/1` | `GET` | استعلام السورة بجميع آياتها وبياناتها | `curl 'http://localhost:3002/v1/quran/surahs/1'` |
| `/v1/quran/ayahs/2/255/words` | `GET` | التحليل الصرفي والإعرابي كلمة بكلمة | `curl 'http://localhost:3002/v1/quran/ayahs/2/255/words'` |
| `/v1/quran/ayahs/36/40/similar` | `GET` | استخراج الآيات المتشابهة نصياً وبنيوياً | `curl 'http://localhost:3002/v1/quran/ayahs/36/40/similar'` |
| `/v1/hadiths/bukhari-1` | `GET` | استعلام الحديث النبوي مع المتن والسند الكامل | `curl 'http://localhost:3002/v1/hadiths/bukhari-1'` |
| `/v1/mustalah/breadth?id=bukhari-1` | `GET` | تصنيف اتساع الحديث (متواتر، مشهور، عزيز، غريب) | `curl 'http://localhost:3002/v1/mustalah/breadth?id=bukhari-1'` |
| `/v1/openapi.json` | `GET` | المخطط الكامل لمواصفة OpenAPI 3.1 | `curl 'http://localhost:3002/v1/openapi.json'` |

يمكنك تجربة جميع العمليات واختبار الردود مباشرة من لوحة **[توثيق الـ API المفتوح](/dashboard/api-docs)** داخل التطبيق.

## 🏢 النسخة السحابية للمؤسسات (Commercial SaaS Edition)

بالإضافة إلى هذه النسخة المحلية المفتوحة، يتوفر للمنصة معمارية سحابية موزعة ومخصصة للمؤسسات والمراكز البحثية والجامعات (**QuranMind Enterprise & SaaS**):
* **معمارية خوادم متعددة الطبقات (Multi-Tier Microservices)** مع خادم Express منفصل وحاويات Docker للخدمات الثقيلة.
* **إدارة الصلاحيات والفرق البحثية (Role-Based Access Control)** مع توثيق Clerk وحصص استخدام لكل فريق.
* **المزامنة السحابية والتخزين المركزي** للفرضيات والأدلة والمذكرات على قواعد بيانات PostgreSQL وSupabase مع الذاكرة المؤقتة الفائقة Redis.
* **بوابات الدفع الإلكتروني المدمجة** عبر البطاقة الذهبية (SlickPay SATIM DZD) والبطاقات الدولية (Stripe).

*(كود النسخة السحابية محفوظ في مستودع خاص ومستقل عن هذا المستودع المفتوح).*
